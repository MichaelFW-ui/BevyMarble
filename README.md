# BevyMarble

BevyMarble 是基于 Rust、Bevy 0.17 和 Avian2D 的双画面 2D 游戏原型。左侧弹珠机产生行动消息，右侧领土战场据此生成单位并进行占领与战斗。

## 运行

在项目根目录执行 `cargo run --release --bin bevymarble`。离线性能分析器的用法和测量范围见[性能分析文档](docs/performance/offline-profiler.md)。
