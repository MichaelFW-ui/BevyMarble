# 弹珠机编辑器

在项目根目录执行 `cargo run --features editor --bin pinball_editor`。正常游戏仍通过 `cargo run --release --bin bevymarble` 启动，直接读取已保存的默认弹珠机。

## 编辑流程

顶部选择要编辑的 profile。可以新建、复制、重命名或删除弹珠机；切换时，尚未保存的编辑仍保留在当前编辑会话中。点“设为游戏默认”，再点“保存全部”，下一次启动游戏就会使用该弹珠机。

左侧列出全部对象，包括四面边界墙、普通钉子、阻挡格点、加倍区、行动区和四队出生点。复选框控制启用状态，搜索框按对象名称过滤。可添加、复制和删除对象，也可以在右侧更改对象类型。

画布上单击选择对象，拖动改变位置，拖动选中对象右下角的蓝色手柄改变缩放。右侧属性面板可以精确设置位置、基础宽高、两个轴的独立缩放、旋转、矩形或椭圆形状、颜色及透明度。椭圆的宽高使用直径；实际尺寸为基础宽高乘以缩放。画布网格吸附以 10 个世界单位为步长，中键平移，滚轮调整视图缩放。

选中“场地与弹珠设置”后，可编辑场地宽高、重力、弹珠初始数值、弹性、摩擦、随机水平初速度和防卡住升力。场地尺寸决定游戏相机范围与越界回收范围，边界墙保持独立可编辑，调整场地尺寸后可按需要重新摆放边界。

## 对象效果

| 对象 | 可编辑效果 |
| --- | --- |
| 墙、挡板、钉子 | 碰撞弹性、摩擦 |
| 加倍区域 | 任意整数倍率、触发后是否回到出生点 |
| 行动区域 | 大球、护盾、机枪、近防炮；行动数值系数；触发后是否回到出生点 |
| 加速区域 | 触发时增加的水平和垂直速度 |
| 出生点 | 所属队伍、位置 |

区域在弹珠进入时触发一次，再次进入可以再次触发。行动区域发送行动后，弹珠数值恢复为 profile 中的初始值。每个队伍需要一个启用的出生点，出生点须位于场地内；编辑器会提示不满足条件的配置，并阻止保存和启动预览。

## 预览与保存

“运行预览”直接使用游戏的 Avian2D 物理、布局生成和碰撞系统，弹珠及其数值在画布上实时显示。行动区域的结果显示在画布上方。预览聚焦弹珠机，领土战场在正常游戏中运行。运行期间修改配置会重建预览，“重置弹珠”可重新开始测试。

所有弹珠机统一保存在 `assets/pinball/profiles.json`。文件包含版本号、默认 profile ID 和所有 profile 的完整数据，初始提供 Classic 和 Zigzag 两种布局。Classic 保留原版布局。保存先写入临时文件，再替换完整文件；若文件被其他程序修改，编辑器会提示重新载入，避免覆盖外部编辑。

撤销与重做覆盖对象属性、增删对象、新建与删除 profile、默认 profile 设置。关闭编辑器时，未保存的修改会显示保存提示。重新载入文件也会提示当前的未保存编辑，并允许撤销恢复。

## 快捷键

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 保存全部 | Command + S | Ctrl + S |
| 撤销 | Command + Z | Ctrl + Z |
| 重做 | Command + Shift + Z | Ctrl + Shift + Z |
| 复制对象 | Command + D | Ctrl + D |
| 删除对象 | Delete / Backspace | Delete / Backspace |
| 微调位置 | 方向键，Shift 为 10 单位 | 方向键，Shift 为 10 单位 |

编辑器使用操作系统的中文字体，支持 macOS 的黑体、Windows 的微软雅黑和 Linux 的 Noto Sans CJK。Linux 环境需提供对应字体文件以显示中文。

## 实现位置

`src/pinball/profile.rs` 定义 profile、对象和统一文件格式，提供验证、加载与保存。`src/pinball/layout.rs` 根据 profile 生成视觉网格与碰撞体。`src/pinball/systems.rs` 执行参数化的区域效果和弹珠逻辑。`src/editor.rs` 负责画布、属性面板、历史记录与物理预览，`src/bin/pinball_editor.rs` 提供独立入口。

编辑器通过可选的 `editor` feature 引入 bevy_egui，常规游戏入口只注册游戏插件。当前文件路径定位到项目的 `assets/pinball/profiles.json`，适合在本仓库中编辑与运行。

## 验证

`cargo test --features editor` 验证 profile 读写、无效数据拦截、保存冲突、历史记录、区域效果、场地回收和场景重建。测试还会逐一打开对象属性面板，确认单纯查看不会改写已保存参数。

具备 GPU 的环境中，执行 `cargo test --features editor editor_renders_profiles_and_runs_shared_physics -- --ignored`，可以离屏验证编辑器画面、真实鼠标拖动、缩放手柄、撤销、保存快捷键和物理预览。设置 `BEVY_LAYOUT_PREVIEW_DIR` 为已有目录，可导出 Classic、预览运行和 Zigzag 的截图。
