# 近防炮数值与冲量

CIWS 的防御基准为单座炮、数值储备充足、2M 敌方大球以每秒 100 个逻辑单位直冲总部，交战起始距离为半个战场宽度（512）。火力基准单独运行索敌、提前量计算、飞行、命中与总部接触判定。实际对局中，弹丸同时沿途染色，染色会消耗弹丸数值并影响拦截结果。

## 弹丸数值

发射间隔为 0.3 秒。开火时读取目标大球的当前体量，确定本发弹丸携带的数值：

`shot_value = min(200000, 25000 + 100000 * sqrt(target_size / 2000000))`

目标体量为 `target_size`，本发所需数值为 `shot_value`，结果四舍五入为整数。本次实际发射数值取所需数值与炮塔剩余储备的较小值，炮塔储备同步扣除相同数值。后续弹丸随目标当前体量调整，已经发射的弹丸继续携带自己的剩余数值。

| 开火时大球体量 | 弹丸所需数值 | 占目标体量 |
| ---: | ---: | ---: |
| 500K | 75K | 15.0% |
| 1M | 约 95.7K | 9.6% |
| 2M | 125K | 6.25% |
| 4M | 约 166.4K | 4.2% |
| 8M | 200K | 2.5% |
| 32M | 200K | 0.625% |

弹丸数值统一用于染色与命中。每占领一格消耗一点，经过己方格子保留数值；命中大球时，扣除量等于弹丸剩余数值与大球剩余体量的较小值。命中护盾时采用相同规则扣除耐久。例如，125K 的弹丸沿途染色 3,000 格，剩余 122K，命中时可扣除大球 122K 体量。数值耗尽或命中单位后，弹丸回收。

平方根增长使大球对应更高的单发数值，同时保留体量增长带来的抗打击能力。200K 上限让超大球需要更长时间的持续交战。开启子弹索敌选项时，拦截敌方子弹采用其当前数值作为本发所需数值，同样受 200K 上限和炮塔储备约束。

## 距离衰减与射程

射程配置位于 [assets/territory/ciws.json](../../assets/territory/ciws.json)，游戏启动时读取；修改后重启游戏即可生效。

| 参数含义 | 配置字段 | 当前值 |
| --- | --- | ---: |
| 最大飞行路程，占战场边长的比例 | `max_range_battle_widths` | 0.7 |
| 射程边缘的弹丸数值保留比例 | `retained_value_at_max_range` | 0.2 |
| 距离衰减曲线指数 | `falloff_exponent` | 1.0 |
| 冲量速度系数 | `impulse_per_value` | 60.0 |

这里的距离基准为战场完整边长 1024，当前最大飞行路程为 716.8。归一化路程为累计路程除以最大路程；保留比例按以下曲线计算：

`retained_fraction = 1 - (1 - retained_value_at_max_range) * pow(distance / max_range, falloff_exponent)`

默认指数为 1，采用线性衰减。指数大于 1 时保留更多近距离数值，衰减集中在远端；指数小于 1 时更早衰减。

| 累计飞行路程，占战场边长的比例 | 逻辑距离 | 数值保留比例，沿途无染色消耗 |
| ---: | ---: | ---: |
| 0 | 0 | 100% |
| 0.175 | 179.2 | 80% |
| 0.35 | 358.4 | 60% |
| 0.525 | 537.6 | 40% |
| 0.7 | 716.8 | 20% |
| 超过 0.7 | 超过 716.8 | 0%，弹丸回收 |

衰减直接消耗弹丸剩余数值。每段飞行按新旧保留比例之比扣除数值，携带舍入余量；同一路程采用不同固定步拆分时，最终数值保持一致。染色消耗继续逐格扣除，后续衰减作用于剩余数值。弹丸反弹后的飞行路程继续累计，最后一段飞行截断在射程边缘，边缘后的弹丸回收。

近防炮在射程内锁定敌方大球，以及设置中启用的敌方子弹。拦截弹穿过总部时继续飞行和染色，单位命中结算用于大球与护盾；普通子弹保留原有单位命中规则。

## 冲量

CIWS 专用弹丸命中大球时，沿弹丸实际飞行方向施加冲量。速度变化按命中前体量折算：

`delta_velocity = projectile_direction * (impulse_per_value * impact_value / size)`

实际扣除体量为 `impact_value`，命中前体量为 `size`，弹丸方向为 `projectile_direction`。冲量速度系数为 `impulse_per_value`，当前配置为 60。沿途染色消耗同时影响命中扣除量与冲量。速度为 100 的 2M 大球首次受到完整 125K 弹丸的正面命中后，速度为 96.25；8M 大球受到完整 200K 弹丸的首次正面命中后，速度为 98.5。

每次命中后沿原运动方向的速度分量保留至少 80%，正面交战持续削弱前进速度。斜向交战保留弹丸冲量的横向分量，使轨迹逐步向总部外侧偏转。普通弹丸保留原有数值结算。

## 固定步验证

测试使用 60 Hz 固定模拟，2M 正面来袭场景采用实际角落总部，分别验证四个炮塔冷却相位（0、0.1、0.2、0.29 秒）。火力基准包含距离衰减，单独测量弹丸命中效果，半场距离 512 的拦截耗时约 7.83～8.10 秒，炮塔耗用数值约 2.29～2.37M，总部全部存活。

8M 斜向场景以距总部 400 的纵向距离、135 的横向偏移进入，速度为 100。原轨迹与总部的距离为 135，小于大球与总部的接触距离 143；测试验证专用弹丸的冲量增加路径与总部的距离。正面场景同时验证连续受击后仍保持向前运动。32M 正面场景验证高体量下的削弱与减速。

染色测试另外启用地形结算，将距离保留比例设为 1，独立测量染色消耗：实际发射的 125K 弹丸飞行一秒占领 3,350 格，剩余数值 121,650，消耗数值与新增格数逐点相等。单格染色后命中大球的测试验证 100 点弹丸最终扣除 99 点体量。距离测试验证边缘保留比例、越界回收、固定步拆分一致、反弹后累计路程，以及目标进入射程后开火。总部接触测试验证拦截弹穿过总部后继续染色并命中后方大球。测试还覆盖开火时目标体量变化、发射数值与炮塔储备守恒、储备不足、飞行中目标体量变化和普通弹丸速度。上述基准测量单个来袭目标；同时出现多个目标时，由现有最近目标索敌规则分配火力。

弹丸数值曲线位于 `src/territory/ciws.rs`，距离衰减与冲量速度系数位于 `assets/territory/ciws.json`。运行 `cargo test --offline --lib ciws -- --nocapture` 可查看交战数据。
